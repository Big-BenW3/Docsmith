The pipeline

Capabilities

Everything a docs team does — automated

Each stage is independently observable, deterministic where it matters, and LLM-assisted only where creativity pays off.

01 / FETCH

GitHub-native ingestion

Pulls the full file tree and contents through the GitHub REST API, with PAT-boosted rate limits and honest truncation flags for very large repos.

02 / DETECT

Scored SDK detection

Deterministic heuristics score the repository first. Only inconclusive scores are escalated to the LLM classifier — fast, cheap, and auditable.

03 / ANALYZE

AST-accurate analysis

Python sources are parsed into an intermediate representation — modules, classes, functions, signatures and docstrings — never guessed from regex.

04 / GENERATE

Grounded generation

The LLM writes real prose — installation guides, quickstarts, API reference pages — grounded in your README, examples and changelog for accuracy.

05 / BUILD

MkDocs site build

Generated markdown is assembled into a themed MkDocs site. If the build fails, the pipeline degrades gracefully and still ships raw sources.

06 / SHIP

Portable artifacts

Results arrive as a docs.zip you can host anywhere, plus a live preview on the dashboard while the job completes.
